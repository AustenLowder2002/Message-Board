# ChipedinAssessment

# Installing Node:
    Go to the Node.js website and install the newest version.
# Installing MySQL workbench:
    Go to the <a href>MySQL workbench website</a> and install MySQL workbench 8
# Instructions to use:
    Open both frontend and backend folders in an integrated terminal.
    On both terminals type npm install.
    Once that is finsished type npm run start.
    In the frontend terminal click the link that says "http://localhost".
